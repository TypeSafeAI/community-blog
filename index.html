Jev Social: bounded decisions, real browser evidence

Jev Social turns one Instagram, TikTok, or LinkedIn research goal into bounded Jev choices and read-only socai actions in the user's Chrome. Posts and media appear as they are captured; a cited report follows without hiding the evidence.

The boundary is simple: Jev chooses, the program validates, and socai reads. The current release starts each socai child with telemetry disabled unless the user explicitly opts in. Its fixed benchmark tasks keep comparative results behind a ten-run, exact-environment publication gate. The same workflow is available as an installable Agent Skill and can use a local System One endpoint.
