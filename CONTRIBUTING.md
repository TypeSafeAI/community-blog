# Contributing to TypeSafeAI Community Notes

> **Unofficial community project — not the official TypeSafe AI team.**

Keep changes focused and dependency-free. Preview the static HTML locally, inspect desktop and mobile layouts, verify links and headings, and describe the checks actually performed in the pull request.

Do not add credentials, private data, fabricated performance claims, or language implying official TypeSafe AI endorsement. Preserve existing attribution and licensing.
